# KUPOL brand assets

Code Canopy: a cyan protective dome over code brackets. All assets are pure SVG with transparent backgrounds, geometric paths, and no external fonts, raster images, gradients, or filters. The wordmark is outlined geometry.

| File | Recommended usage |
| --- | --- |
| `kupol-icon.svg` | Square icon for GitHub avatars, product tiles, and pitch decks; use on a light background. |
| `kupol-logo-light.svg` | Website headers, documents, and pitch decks on white or light backgrounds. |
| `kupol-logo-dark.svg` | Website headers and pitch decks on deep navy or other dark backgrounds. |
| `kupol-favicon.svg` | Browser favicon; simplified 16-unit geometry with a 2-unit canopy stroke for 16×16 and 32×32 display. Use on a light background. |

## Colors

- Primary / light-background wordmark and brackets: `#0F172A` (deep navy).
- Accent / canopy: `#22D3EE` (cyan).
- Dark-background wordmark and brackets: `#F8FAFC` (off-white).
- Suggested light background: `#FFFFFF`.
- Suggested dark background: `#0F172A`.

## Usage

Preserve the aspect ratio. Keep clear space around the mark of at least one canopy stroke width. Use the supplied favicon at tiny sizes; use the regular icon for larger placements. Use the full wordmark at 120 CSS pixels wide or larger. Do not add shadows, gradients, distortions, or outlines.

For a website favicon: `<link rel="icon" type="image/svg+xml" href="/brand/kupol-favicon.svg">`. The favicon has a transparent background and navy brackets; provide a light surface or a separate light-bracket variant if your browser theme requires dark-surface support.
