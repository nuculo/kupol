How it worksКак это работает

01

Point it at a treeУкажите каталог

kupol scan . walks the repo (honoring .kupol.yml ignore rules) and runs the scanner plugins.

kupol scan . обходит репозиторий (с ignore из .kupol.yml) и запускает плагины сканера.

02

Read the reportЧитайте отчёт

Table, JSON, or Markdown. Severity and file/line for each finding.

Таблица, JSON или Markdown. Severity и файл/строка для каждой находки.

03

Fail the buildЛомайте сборку

In CI, fail on high (see .kupol.yml and .github/workflows/scan.yml). GitHub or GitLab — either host is fine.

В CI падайте на high (см. .kupol.yml и .github/workflows/scan.yml). GitHub или GitLab — без разницы.

InstallУстановка

# from the repo, after cargo build --release or unpacking a Release
chmod +x install.sh bin/kupol
./install.sh ./target/release/duo-agents
kupol scan . -f table
