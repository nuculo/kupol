04 / FROM SOURCE TO FIRST SCAN

Put up your dome.

Build from source with Rust and Cargo, then install the CLI using the included shell script.

Installation docs & release binaries ↗

Shell commands below are for Linux / macOS.
Ensure ~/.local/bin is on your PATH.

SH / BUILD FROM SOURCE
git clone https://github.com/nuculo/kupol.git
cd kupol
cargo build --release
./install.sh ./target/release/duo-agents

kupol scan .
