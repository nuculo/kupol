# 🛡️ Duo Architecture Guardian — Питч-дек для Хакатона

**Трек:** AI Security Agents for GitLab Duo
**Слоган:** _Автоматизированный Архитектор Безопасности в ваших Merge Requests._

---

## 🛑 Проблема

Современный DevSecOps полагается на CI-пайплайны, запускающие AST/SAST инструменты *после* того, как код уже написан, что создает узкое место (bottleneck). Команды безопасности вынуждены вручную проверять изоляцию кода и границы архитектуры, что приводит к задержкам обратной связи. Более того, традиционным сканерам не хватает контекстного понимания **Радиуса Поражения (Blast/Impact Radius)** — они не знают точно, какие микросервисы, базы данных и API будут скомпрометированы, если одна утилитарная функция содержит уязвимость.

## ⭐ Наше Решение: Duo Architecture Guardian

**Duo Architecture Guardian** — это продвинутый AI-агент безопасности, созданный специально для экосистемы GitLab (вдохновлен подходом *promptfoo*). Он живет рядом с разработчиком и нативно интегрируется в GitLab Merge Requests и IDE.

Вместо банальной проверки на синтаксические ошибки, он строит `EntityGraph` всей экосистемы (Rust/JS), идентифицируя компоненты, эндпоинты и запросы к БД. Агент параллельно запускает **8 кастомных плагинов безопасности OWASP**, вычисляя серьезность уязвимости на основе **Радиуса Поражения (алгоритм Trust Decay)**.

Если функция `unsafe_raw_query()` уязвима, Guardian автономно трассирует граф вызовов вплоть до `UserService` и эндпоинта `POST /auth/login`, показывая *истинный* радиус поражения.

## 🎯 Ключевые Возможности и Завершенные Эпики

### 1. 🚄 Высокопроизводительный Actor Engine (Rust)
Построен на передовой 12-акторной архитектуре (`mpsc`/Tokio), поддерживающей параллельные фазы анализа: парсинг AST, выявление дрифта архитектуры (Drift Analysis), плагины безопасности и сбор телеметрии.
- **Бенчмарки:** Платформа всесторонне протестирована с использованием zero-copy Arc примитивов, lock-free очередей (seqlock/arc-swap) и work-stealing планировщиков, достигнув экстремальной пропускной способности **11.13M сообщений/сек** в синтетических высоконагруженных сценариях (Akka-подобная производительность).
- **Скорость Сканирования:** Сканирование безопасности реальных кодовых баз выполняется за **<200мс**, обеспечивая мгновенную обратную связь в MR-пайплайне.

### 2. 🧩 Eval Pipeline в стиле Promptfoo
- **8 Плагинов Безопасности:** Охватывают стандарты CWE (SQL-инъекции, захардкоженные секреты, unsafe-блоки, криптография и т.д.).
- **Движок Оценки (Evaluation Engine):** Назначает динамический CVSS Risk Score, основываясь на серьезности радиуса поражения.

### 3. 🖥️ Интерактивный React Dashboard (@xyflow/react)
- **Real-Time Web UI:** Просмотр критических находок и динамическая фильтрация уязвимостей в реальном времени.
- **Вкладка Architecture Graph:** Иерархический граф на базе Dagre отображает микросервисы и API приложения. Уязвимые компоненты визуально пульсируют **неоновым красным цветом**, чтобы вживую продемонстрировать радиус поражения.

### 4. 🦊 Нативная Автоматизация GitLab CI/CD
- **`duo-agents init`:** Генерирует файл `.gitlab-ci.yml` за одну секунду.
- **Автоматические Комментарии к MR:** Нативная аутентификация через GitLab API. Робот публикует подробные Markdown-отчеты по безопасности прямо в комментариях Merge Request при каждом пуше.

### 5. 🤖 MCP Сервер (Model Context Protocol) 
- Работает как полнофункциональный нативный **JSON-RPC Agent Tool**.
- Бесшовно интегрируется в **Cursor** и **Claude Desktop**. Другие ИИ-ассистенты теперь могут локально вызывать команду `scan_codebase`, автономно выполняя полноценное архитектурное сканирование безопасности!

- **Backend:** Rust 🦀, Axum (HTTP + WebSockets), Tokio (Actor Model), petgraph, syn.

- **Протоколы интеграции:** GitLab API, MCP (stdio/JSON-RPC 2.0).
